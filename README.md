# Дашборд Ducati Parfums

Воронка трафика по Яндекс Директу, Авито и ВК: показы → клики → визиты → переходы на маркетплейс.
Страница — один самодостаточный HTML: данные зашиты внутрь, внешних библиотек нет.

Репозиторий публичный, потому что GitHub Pages иначе не работают. Страница закрыта от
поисковиков (`noindex` в разметке и `robots.txt`), но по прямой ссылке открывается без пароля —
не публикуйте ссылку там, где её не должны видеть.

## Как обновляется

- **Автоматически** — workflow `.github/workflows/dashboard.yml` каждое утро в 09:00 МСК
  заново ходит в API и коммитит `index.html`, если данные изменились. Токены лежат в секретах
  репозитория: `YM_TOKEN`, `YD_TOKEN`, `AV_CLIENT_ID`, `AV_CLIENT_SECRET`, `AV_ACCOUNT_ID`, `VK_TOKEN`.
- **Вручную** — вкладка Actions → Пересборка дашборда → Run workflow.
- **С рабочей машины** — из корня проекта Ducati: `python3 "Аналитика и скрипты/publish.py"`.

## Что где

| Файл | Что это |
|---|---|
| `index.html` | сам дашборд, его отдаёт GitHub Pages |
| `scripts/dashboard.py` | сборщик: ходит в четыре API и подставляет данные в шаблон |
| `scripts/шаблон.html` | вёрстка и вся логика дашборда, метка `/*__ДАННЫЕ__*/` — куда кладутся данные |
| `scripts/metrika.py`, `direct.py`, `avito.py`, `vk.py` | клиенты API, копии из основного проекта |

Править внешний вид нужно в `scripts/шаблон.html` **основного проекта** — здесь лежат копии,
которые перезаписываются при каждой публикации.
